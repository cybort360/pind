## Template name

Pind — Client Review & Approval Portal

## One-line description

A white-label client portal for sharing revisions, pinning precise feedback, capturing approval, and retaining a decision receipt.

## Brief project description

Pind is a remixable client review and approval workspace for freelancers, creative studios, and agencies. Teams upload revisions, share a project-scoped review link, collect visual feedback directly on the work, resolve each point, and capture approval or change requests against an exact file version. Every remix includes a polished studio dashboard, client portal, realistic sample data, responsive design system, activity trail, workspace branding, and optional PostgreSQL, Resend, Cloudinary, and Slack integrations.

## What makes it useful

Client feedback is normally fragmented across email, messaging apps, calls, and cloud folders. Pind keeps the revision, comment, response, decision, and timestamp in one place. A remixer can use it as a working portal immediately, then replace the fictional Northstar Creative branding and connect their preferred services.

## Key features

- Studio dashboard with attention metrics and live activity.
- Searchable project and client management.
- Revision uploads with Cloudinary or local fallback storage.
- Precise pinned comments on visual work.
- Dedicated project-scoped client review links.
- Approve/request-changes workflow.
- Timestamped, printable approval receipts.
- Milestones, revision library, notifications, and audit timeline.
- White-label portal settings.
- Dedicated design-system route.
- Seeded sample data and one-click demo reset.

## Integrations

- PostgreSQL via `DATABASE_URL`.
- Resend for client invitations.
- Cloudinary for uploaded deliverables.
- Slack webhooks for client decision notifications.

All integrations degrade gracefully, so judges can explore every core workflow before configuring secrets.
